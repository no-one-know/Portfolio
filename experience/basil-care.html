01 · CONVERSATIONAL AGENTS & LONGITUDINAL DATA

Interactive Health Chatbot & Trend Orchestration

Diagnostic laboratory reports contain dense biological data, disjointed reference ranges, and complex medical terminology that users struggle to contextualize over time. I engineered a conversational system allowing patients to query longitudinal health records seamlessly.

The Problem

Disjointed Lab Reports & Historical Blind Spots

  • Diagnostic test results were siloed across disparate PDF files from multiple testing laboratories.
  • Users had no way to ask natural language questions regarding biomarker trends (e.g. tracking fasting glucose or lipid profiles across consecutive quarters).
  • Required high-accuracy medical validation to ensure clinical advice boundaries were strictly maintained.
Engineering Strategy

Stateful Orchestration & Historical Profiling

  • Architected an orchestration state machine that correlates historical test records into a unified patient timeline.
  • Implemented natural language intent parsing capable of detecting biomarker queries, temporal comparisons, and normal vs. abnormal threshold inquiries.
  • Designed proactive diagnostic insights prompting users when biomarker values crossed clinical attention thresholds.

Extraction Engineering

Prompt Optimization & Strict Schemas

  • Developed structured prompt templates and few-shot examples for arbitrary lab layouts across diverse hospital formats.
  • Enforced runtime schema validation using Pydantic, flagging any mismatched units (e.g. mg/dL vs. mmol/L) for secondary verification.
  • Reached a verified 98.3% extraction accuracy across benchmark test suites of historical reports.
Hallucination Mitigation

Grounded RAG with Source Citations

  • Indexed medical terminology, clinical reference ranges, and lab footnotes into vector embeddings.
  • Formulated a RAG retrieval system that restricts generative responses exclusively to the retrieved source chunks.
  • Every chatbot response provided clickable footnote citations back to the specific test row in the user's uploaded document.

03 · HYBRID MOBILE ARCHITECTURE

High-Performance React ↔ Native Android Bridge

To ship rapid iterative UI updates without constant Play Store deployment cycles, the application leveraged a hybrid architecture: React web applications running inside a native Android WebView container.

The Challenge

Bridging Web & Native Device Features

  • Standard WebView postMessage communication suffered from serialization latency, unhandled promise rejections, and loose typing.
  • The web interface required hardware-accelerated camera access for document scanning, secure biometrics, and offline persistence.
  • Real-time diagnostic events and live chat required persistent bidirectional syncing.
The Implementation

Type-Safe JS Bridge & WebSockets

  • Built an asynchronous, type-safe JavaScript-to-Android bridge supporting promise-based RPC calls between React components and Java/Kotlin handlers.
  • Integrated native device features (camera capture, document edge detection, and secure storage) accessible directly via React hooks.
  • Maintained real-time diagnostic synchronization using persistent WebSockets with automatic reconnection handlers.

04 · SECURITY & IDENTITY

OAuth 2.0 & OpenID Connect (OIDC) Infrastructure

Identity Module

Enterprise-Grade Authentication

Designed and deployed an end-to-end OAuth 2.0 and OpenID Connect (OIDC) authorization module to safeguard sensitive protected health information (PHI).

  • Implemented secure JWT authentication with short-lived access tokens and sliding refresh token rotation.
  • Enforced fine-grained Role-Based Access Control (RBAC) across patient, physician, and admin API boundaries.
Compliance & Reliability

Security & Protection

Protected patient data with AES-256 encryption at rest in MongoDB and TLS 1.3 in transit. Zero security vulnerabilities identified during vulnerability assessments.
